# もぐらたたき（3×3）

AI勉強会で作っている、ブラウザで遊べるもぐらたたきゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 「スタート」を押す
3. 30秒の間に、出てきたもぐら（🐹）をクリック（タップ）する

## 今のルール（v0.1 たたき台）

- 穴は 3×3 の 9個
- 制限時間 30秒
- もぐらは 0.8秒ごとにランダムな穴へ移動
- 1回たたくと 1点
